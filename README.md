# Censurados Film Festival

Web oficial de Censurados Film Festival — cine, censura y derechos humanos (2014–2026).
https://censuradosfilmfestival.com

Web estática (HTML + CSS), sin dependencias ni compilación. Se publica tal cual desde la rama `main`.

- `index.html` — portada
- `festival.html` — el festival
- `ediciones.html` — archivo de las doce ediciones
- `cine-censurado.html` — qué es la censura y selección de películas
- `organizadores.html` — La Combi y Tupac, y contacto
- `css/estilos.css` — estilos (paleta de la línea gráfica oficial)
- `img/` — logos, fotos y carteles
